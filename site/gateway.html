How a licence would clear

  1. Contract (on-chain). A licensing contract on the TRON Virtual Machine, denominated in USDT (TRC-20) rather than a native token.
  2. Daemon (off-chain). Runs on the operator’s own machine. It hashes the build logs into a reviewable tree and pauses for a human to approve the configuration before anything is broadcast. No blind script touches a rig.
  3. Energy. TRON meters execution as Bandwidth and Energy rather than a gas auction. Renting Energy moves the execution cost off the end user.
  4. Settlement. The daemon broadcasts the validation state and the payment; DPoS confirmation unlocks the compiled workspace.

Every figure here is someone else’s

~3 second confirmation and 27 Super Representatives are vendor figures — published parameters of the TRON network, not timings taken on this machine. Block times are a target, not a guarantee.

“Effectively zero fee” is projected. Energy rental does not make execution free; it moves the cost from the end user to whoever rents the Energy. Calling that zero would describe an accounting choice as a physical property.

Nothing here is measured, because nothing has run.

Why it reads offline

There is no deployed contract, no wallet, no daemon and no key material on this box. Signing belongs on the operator’s own machine, never in the environment of a public-facing web process.

This is a 16 GB consumer card, and it is a test bench

Chat and image never run at the same time here. A lock hands the GPU to exactly one surface and the other waits, because both weight sets do not fit in 15.92 GiB at once — and when they swap, we wait for the driver to actually hand the memory back before the next one starts. If you are queued behind someone, that is not a bug; it is one card doing one thing at a time.

RavenCalc is the exception — it is SymPy on the CPU, so it never touches the GPU and never queues. Everything here is a demonstration of the stack on the smallest machine we would ever ship, not a statement of capacity. A server we spec for you would not be sharing one GPU with itself.
