What this reads

Antminer rigs over the bmminer JSON-RPC API and MicroBT/Whatsminer over btminer, using pyasic 0.75.0. Both are polled over the network, so this surface never touches the GPU lock and is never evicted to serve a page.

Why it says offline

There is no mining hardware attached to this machine. Rather than draw a dashboard of invented numbers, the unit reports offline and every reading stays empty until a rig answers. Any figure this page ever shows is measured off real hardware.

Operator surface

This is a tool for hardware on the operator's own network — your rig is on your LAN and this server cannot reach it. It is disabled unless SYM_ASIC_ENABLED and SYM_ASIC_TOKEN are both set, so a misconfiguration fails closed.

This is a 16 GB consumer card, and it is a test bench

Chat and image never run at the same time here. A lock hands the GPU to exactly one surface and the other waits, because both weight sets do not fit in 15.92 GiB at once — and when they swap, we wait for the driver to actually hand the memory back before the next one starts. If you are queued behind someone, that is not a bug; it is one card doing one thing at a time.

RavenCalc is the exception — it is SymPy on the CPU, so it never touches the GPU and never queues. Everything here is a demonstration of the stack on the smallest machine we would ever ship, not a statement of capacity. A server we spec for you would not be sharing one GPU with itself.
