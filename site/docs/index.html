Prefer the socket to the poller

GET /api/ws upgrades to a WebSocket and then stays quiet until the machine actually changes — one handshake, one baseline snapshot, then patches of a few dozen bytes. Polling /api/status works too and supports If-None-Match, so an unchanged rack costs a bare 304 with no body.

Frames. Server sends welcome → rack (full) → patch (deltas, units addressed by id) and bus (an agent announcing what it did). Client may send ping, rack, chat, calc, remix — rate limited exactly like the REST routes, because holding a socket open is not a way around the caps.
