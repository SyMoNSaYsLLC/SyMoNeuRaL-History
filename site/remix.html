Playlists that are ordered sets, not piles of songs.

Remix asks the same local 7B that answers questions on the chat page. One model, one GPU, one server underneath — which is the whole architecture in one page.

SyMoNeuRaL Remix idle
Describe a mood, a night, a drive, a room. You get an ordered set rather than a pile of songs — sequenced so it actually flows.

Parameters

Remix is a client of the chat surface rather than its own model — the same 7B that answers questions writes the sequence, which is what “one server underneath” means in practice. So it queues behind chat, and behind image.

Generation only, here. Resolving these against Spotify and writing the playlist to an account needs OAuth, and that half runs on the box behind admin auth — not from a public page.

This is a 16 GB consumer card, and it is a test bench

Chat and image never run at the same time here. A lock hands the GPU to exactly one surface and the other waits, because both weight sets do not fit in 15.92 GiB at once — and when they swap, we wait for the driver to actually hand the memory back before the next one starts. If you are queued behind someone, that is not a bug; it is one card doing one thing at a time.

RavenCalc is the exception — it is SymPy on the CPU, so it never touches the GPU and never queues. Everything here is a demonstration of the stack on the smallest machine we would ever ship, not a statement of capacity. A server we spec for you would not be sharing one GPU with itself.
