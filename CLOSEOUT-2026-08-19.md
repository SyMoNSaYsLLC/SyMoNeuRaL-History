Reviewed the uncommitted work: two new backend apps (`symoneuralstudio`, `symoneuralexp`),
their pages and generators, plus the api.py wiring, Caddyfile block, governor arm, masthead
creed and CSS.

**Verdict: the plumbing is sound and the wiring is complete. The defect class is not broken
code — it is comments and docstrings that describe callers, tests, docs and behaviour that do
not exist.** That is the "embellishing" you flagged, and it is a direct breach of the honesty
rules in `.claude/CLAUDE.md`, because a comment claiming a test guards something is exactly as
misleading as a gauge that isn't reading anything.

Everything below was verified by reading the code; items marked **EXECUTED** were confirmed by
running the module on the box.

## 1. Ship blockers — correctness

1. **`routes.py` `_intercept_prompt`: the lease-release task is unreferenced.**
   `asyncio.create_task(_release_when_done(), ...)` with no strong reference kept. If it is
   GC'd mid-await, `_KEEPER.leave()` never runs, `_count` never returns to zero, and the
   supervisor holds the governor lock for the life of the process — the single-tenant-card
   failure `CLAUDE.md` forbids. Keep it in a module-level set with a done-callback.

2. **`tools_impl/host.py` `run_command`: the timeout does not bound the request.**
   On `TimeoutExpired`, Python kills only `/bin/sh`, then calls `communicate()` again *with no
   timeout*, blocking until every inherited pipe closes. `run_command("nohup sleep 99999 &")`
   hangs that call forever. Sync tools dispatch through `anyio.to_thread.run_sync`, so N such
   calls eat N of the 40 default threads and eventually stall the **whole serving API**, not
   just Studio. Use `start_new_session=True` + `os.killpg`. The module docstring currently
   promises the opposite.

3. **`tools_impl/fs.py` `read_file`: `max_bytes` does not bound I/O.**
   `p.read_bytes()[:max_bytes]` reads the entire file first. `read_file("/proc/kcore")` or any
   multi-GB `.gguf` under `backend/models/` OOMs the serving interpreter. Open and
   `read(max_bytes)`.

4. **`/api/studio/events` crashes on the first latent preview. EXECUTED.**
   `comfy.py` yields `{"type":"preview", "binary": bytes(...)}`; `ws.send_json` raises
   `TypeError: Object of type bytes is not JSON serializable`, which the broad handler then
   reports to the operator as `comfyui_unreachable` / "fix: scripts/comfyui.sh start" — a
   wrong diagnosis for a serialisation bug. The endpoint also has **no consumer anywhere in
   the repo**, which is why this went unnoticed.

5. **`routes.py` `/state` 500s on a checkout where workspace discovery fails.**
   It calls `workspace.root()`, which *raises* `RuntimeError` rather than returning `None`, so
   the tokenless status endpoint 500s instead of reporting absence. This makes
   `page.js`'s `ws.root || 'not found'` / `'set SYM_STUDIO_ROOT'` branch dead code and
   contradicts `workspace.py`'s own "ROOT is None and every disk tool says so".
   `__init__.status()` and `mcp_server.main()` have the same raise.

6. **`symoneuralexp`: a config value leaks to unauthenticated callers. EXECUTED.**
   `registry.check_config` puts the offending value **verbatim** into its failure message,
   that message goes into the trace, and `GET /api/exp/events` is open. A manifest with
   `config: {interval: "sk-live-SECRET"}` produces the public trace line
   `fiber/fail | config for c: 'interval' wants float, got str ('sk-live-SECRET')`, and
   `page.js` prints every field of every event. This directly falsifies the claim in
   `api.py`, `routes.py`, `page.html` and `trace.py` that no configured value reaches a
   tokenless reader. Redact the value; keep the type.

7. **`symoneuralexp`: a failed plugin leaves live children behind. EXECUTED.**
   `Fiber._start`'s failure path calls `_dispose_effects()` only — it never disposes
   `self.children` the way `_unwind` does. A plugin that calls `ctx.plugin(child)` then raises
   ends `parent failed | child active | services [':kid']`: an orphaned, unreachable,
   undisposed fiber. `fiber.py` claims a half-mounted plugin "is the one state this runtime
   will not leave anything in".

8. **`symoneuralexp`: one bad entry aborts the whole manifest. EXECUTED.**
   `resolve_ref`'s `importlib.import_module` is unwrapped, so a bad `module:attr` raises
   `ModuleNotFoundError`; `_mount` catches only `ContextError`, so it escapes `apply()`. That
   is the exact opposite of the "one bad entry must not stop the other eleven" promise in both
   `_mount`'s docstring and `fiber.py`.

9. **`symoneuralexp`: `boot()` is not idempotent. EXECUTED.**
   It guards on `self.source`, which `Loader.apply` sets *after* the awaits it is meant to
   serialise. Two concurrent first requests run `apply` twice. `apply` also leaves
   `source = None` for a dict manifest, so `boot()` re-runs after any `POST /apply`.

10. **`symoneuralexp`: `Context.effect`'s disposer runs its cleanup twice if called twice.
    EXECUTED.** `Fiber.add_effect`'s `run_once` removes the entry then calls `cleanup()`
    unconditionally.

11. **`symoneuralexp`: an oscillating settle fails silently.** `Runtime.settle` raises on
    `MAX_PASSES`, but `registry.mount` launches it via `create_task` and never awaits it, so
    the failure surfaces only as an asyncio "Task exception was never retrieved" warning —
    never on a fiber, in the trace, or in an API reply.

12. **`symoneuralexp`: a non-ASCII token is a 500, not a 401. EXECUTED.**
    `hmac.compare_digest` raises `TypeError` on a non-ASCII `str`; `GET /state` calls
    `_may_write` outside any `try`, and callers catch only `Denied`/`ContextError`.

Each of these is a comment or docstring asserting a guarantee the tree does not provide.
These are the ones worth fixing rather than deleting, because they name the protection someone
will later assume is in place.

## 5. Security posture — accepted risk, but three things are misdescribed

The unrestricted filesystem and `shell=True` command execution in `tools_impl/` are
**deliberate and correctly documented in five places**, matching `apps/voice`. I am reporting
them as accepted risk, not defects. What is *mis*described:

- **`_mint_cookie` claims `HttpOnly` means "page script cannot read the operator token back
  out."** True of the cookie — but the document loaded at `/studio/comfy/?token=…` is
  **ComfyUI's own frontend**, and any of its JS (or any installed custom-node frontend
  extension) can read `location.search` and exfiltrate the token that grants host RCE. The
  stated protection is defeated by the delivery mechanism. Same `?token=` channel exists in
  exp's `gate.py` and is unused by its page — an unused credential channel that lands in the
  access log.
- **`env_get`'s masking emits `<set, N chars, ends 'xxxx'>` for `SYM_STUDIO_TOKEN`.** The
  masking exists precisely because the value reaches LLM context, the DOM and the API log;
  a length plus a 4-char suffix in all three still narrows the search materially.
- **`comfy.base_url()` re-reads `SYM_COMFY_URL` on every call and `host.env_set` writes
  `os.environ` in-process**, so `env_set("SYM_COMFY_URL","http://169.254.169.254")` turns the
  gated proxy into a relay for any internal address. A pivot rather than an escalation (the
  actor already has `run_command`), but `comfy.py`'s "Loopback by default: the public surface
  is FastAPI's" reads as a deployment property when it is a mutable process variable.
- `/state` says it "does not read files, does not list the workspace contents" while returning
  the **absolute workspace root** and ComfyUI's entire `GET /system_stats` body (GPU model,
  VRAM, torch/python versions, OS) to any unauthenticated visitor.
- `studio.router` is deliberately excluded from `throttled_for("studio")`, so there is no
  throttle or lockout on unlimited token guesses. `hmac.compare_digest` closes the timing
  channel only. The README's worked example uses `SYM_STUDIO_TOKEN=devtest`.

## 6. `tools/build_studio.py` destamps the page

The generator is genuinely deterministic — no clock, RNG, UUID, network or GPU — and two runs
are byte-identical, exactly as its docstring claims. But it does **not** reproduce the
committed `site/studio.html`: I reconstructed the transform read-only and diffed.

- `expected == site/studio.html` → **False**
- `expected == destamp(site/studio.html)` → **True** (`\?v=[0-9a-f]{10}`)

The committed page carries 9 cache-bust stamps that `build_studio.py` does not emit; they come
from `tools/build_cachebust.py`. So a bare `python3 tools/build_studio.py` **destamps the page**
and produces a diff that reads as a harmless refresh — the precise hazard `CLAUDE.md` records
("a run of `build_pages.py` here silently destamped seven pages"). `README.md` does say
`build_cachebust.py` ALWAYS LAST, but nothing in `build_studio.py` itself warns of it, unlike
the repo-level guidance. Add the warning, and add an assertion so a destamped
`site/studio.html` fails a test.
